# 근거 목록

커리큘럼의 「국내 근거」·「글로벌 비교」가 가리키는 출처다. 튜터는 조문·기한·금액·대상 기준을 말하기 전에 여기를 본다([tutor/legal-sources.md](../tutor/legal-sources.md)).

- **확인 상태**: 확인 = 공식 원문에서 「확인 내용」 칸까지 확인 / 부분 = 명칭·URL과 일부만 확인(칸에 무엇이 미확인인지 적음) / 미확인 = 커리큘럼에서 참조하지 않음.
- **변동**: 「잦음」이면 최근 개정·시행예정·진행 중 개정이 있다. 튜터는 세션 중 공식 출처로 현행 여부를 다시 확인한다.
- 이 목록은 학습용 요약이다. 원문이 우선한다.
- 2026-11-14 조회 사정: 국가법령정보센터(law.go.kr)가 시스템 점검(2026-11-13 21:00 ~ 11-14 21:00) 중이어서, 법률·시행령 본문은 점검 안내가 대체 사이트로 지정한 국회법률정보시스템(<https://likms.assembly.go.kr/law/>, 법령명 검색) 현행 전문으로 확인했다. 표의 law.go.kr 주소는 인용용 고정 주소다.
