# go-security

정보보호·개인정보·사이버보안을 AI 튜터와 함께 익히는 학습 워크스페이스입니다. 국내 법·제도(개인정보 보호법, 정보통신망법, ISMS-P 등)를 뼈대로 배우고, GDPR·ISO/IEC 27001·NIST CSF·SOC 2 같은 글로벌 기준과 비교합니다. 개발자뿐 아니라 경영·운영 관리자, 개인정보·보안 실무 담당자를 위한 곳입니다.

정해진 강의 자료는 없습니다. 이 리포에는 커리큘럼의 큰 지도, 확인된 근거 목록, 튜터의 행동 규칙만 있습니다. 도식과 조사 자료를 조합한 HTML과 업무 문서 초안은 대화하면서 튜터와 함께 그 자리에서 만듭니다.

> **학습용입니다. 법률 자문이 아닙니다.** 법령과 고시는 자주 바뀝니다. 튜터는 조문·기한·금액을 공식 출처에서 확인한 것만 말하도록 되어 있지만, 실제 회사 결정은 법령 원문과 담당자·전문가 확인을 거쳐 주세요.

## 시작하기

준비물은 Git, [GitHub CLI](https://cli.github.com)(`gh`), Claude Code 또는 Claude Desktop입니다. 비공개 리포이므로 먼저 GitHub에서 보낸 초대를 수락하고, 터미널에서 `gh auth login`으로 로그인합니다. 다른 설치는 필요 없습니다.

원하는 폴더(예: 바탕화면이나 문서 폴더)에서 클론합니다. macOS·Linux 터미널과 Windows PowerShell 모두 같은 명령입니다.

```bash
gh repo clone holmesLee-ws/go-security
cd go-security
```

**Claude Code**

```bash
claude
```

처음 열면 이 폴더를 신뢰하는지 묻습니다. 기본 선택은 「No, exit」이므로 Enter만 누르면 종료됩니다. **아래 화살표로 「Yes, I trust this folder」를 고른 뒤 Enter**를 누르세요. 그래야 학습 기록 저장과 자료 조사를 튜터가 묻지 않고 진행합니다.

**Claude Desktop**

Code 탭에서 클론한 `go-security` 폴더를 선택합니다. Chat 탭이 아니라 Code 탭이어야 튜터 규칙이 적용됩니다. 학습 기록 저장이나 조사 때 권한 창이 뜨면 허용을 고르세요(Desktop 경로는 아직 실제로 확인하지 못했습니다 — 아래 「Desktop 확인」).

어느 쪽이든 「안녕」이라고 입력하면 시작합니다. 「ISMS-P 알려줘」처럼 바로 궁금한 것을 말해도 됩니다.

## 이렇게 진행됩니다

1. 왜 배우려는지, 업무 경험은 어떤지 짧게 묻고, 영역마다 사례 문제를 하나씩 풀어 출발점을 찾습니다.
2. 모듈마다 먼저 사례 문제로 수준을 확인합니다. 이미 아는 내용이면 바로 넘어갑니다.
3. 국내 법·기준으로 먼저 판단해 보고, 같은 상황을 글로벌 기준과 비교해 봅니다.
4. 튜터가 내 답을 반영한 HTML(데이터 흐름도, 사고 타임라인, 위험 매트릭스 등)을 만들고, 체크리스트·절차 같은 업무 문서 초안을 함께 씁니다.
5. 튜터는 내 답을 보고 너무 빠른지, 보강이 필요한지, 지루한지 판단해 속도와 방식을 바꿉니다.
6. 다음에 다시 열면 기록을 읽고 복습 질문 하나로 이어갑니다.

언제든 말로 요청하면 됩니다. 「이건 넘어가자」, 「너무 어려워」, 「그림으로 보여 줘」, 「우리 회사 사례로 해 줘」처럼요.

| 명령 | 하는 일 |
|---|---|
| `/learn [모듈 또는 주제]` | 시작하거나 이어가기 |
| `/check [모듈 또는 영역]` | 빠르게 수준 확인하고 건너뛰기 |
| `/map` | 지금까지의 현황과 다음 모듈 |
| `/pace [너무 빠름·너무 느림·지루함·어려움]` | 속도와 난도 바꾸기 |

## 실제 정보는 넣지 마세요

회사·업무 상황을 말해 주면 튜터가 사례로 씁니다. 하지만 **실제 고객·직원 개인정보, 비밀번호·키, 내부 시스템 주소, 실제 사고의 세부**는 넣지 말고 예시 값으로 바꿔 주세요. 대화 내용은 Claude 서비스로 전송되고, 튜터의 웹 조사 질의는 외부 검색 서비스로 나갑니다.

## 구성

| 위치 | 내용 |
|---|---|
| [curriculum/map.md](curriculum/map.md) | 커리큘럼 지도(영역 B·P·M·O와 졸업 프로젝트) |
| [curriculum/sources.md](curriculum/sources.md) | 법령·기준 근거 목록(공식 URL·조회일) |
| [CLAUDE.md](CLAUDE.md), [tutor/](tutor/) | 튜터의 행동 규칙 |
| `.claude/` | 명령과 권한 설정 |
| `learner-template/` | 학습 기록의 빈 양식 |
| `learner/` | 내 기록, 내 HTML(`studio/`), 내 업무 초안(`work/`). 처음 시작할 때 생깁니다 |

`learner/`는 Git에서 제외되어 내 컴퓨터에만 남습니다. 그래서 `git pull`로 커리큘럼·근거 목록을 업데이트해도 기록이 충돌하지 않습니다. 컴퓨터를 옮길 때는 이 폴더를 직접 복사하세요.

## 튜터가 쓰는 권한

튜터는 묻지 않고 내 학습 기록, `learner/studio`의 HTML, `learner/work`의 초안을 쓰고, 웹을 조사하고, 만든 HTML을 열 수 있습니다. 그 밖의 파일을 고치거나 명령을 실행할 때는 평소처럼 허락을 구합니다.

## 관련 워크스페이스

go-develop(개발), go-ai(AI 거버넌스), go-control(내부통제), go-hr(인사·노무), go-project-management(프로젝트 관리)와 겹치는 주제는 지도에 「경계·연결」로 표시하고 여기서는 깊게 다루지 않습니다.

## Desktop 확인(1분)

Claude Desktop의 Code 탭에서 이 폴더를 열고 「안녕」을 보냅니다. 코딩 도우미가 아니라 튜터의 인사와 질문 하나가 나오고, 두세 번 답한 뒤 `learner/state.json`이 생기면 정상입니다. 튜터가 준 `learner/studio/…html` 경로를 클릭해 열리는지도 봅니다.
